访问令牌与权限边界

只读 {{if .Data.ReadConfigured}}已配置{{else}}未启用{{end}}

WVC_METRICS_TOKEN

用于 Prometheus 和只读 API。不能创建、开关机或删除虚拟机。

运维 {{if .Data.OperatorConfigured}}已配置{{else}}未启用{{end}}

WVC_API_TOKEN

可读取资源、创建虚拟机和执行生命周期操作；不能删除虚拟机。

管理员 {{if .Data.AdminConfigured}}已配置{{else}}未启用{{end}}

WVC_API_ADMIN_TOKEN

拥有运维令牌全部权限，并可删除已关机虚拟机定义。仅授予受控自动化系统。

令牌至少 32 个可打印 ASCII 字符，只通过 Authorization: Bearer <令牌> 请求头发送。不要把令牌放入 URL、截图、工单或前端代码。

基础地址

export WVC_BASE_URL="http://127.0.0.1:8080"
export WVC_API_TOKEN="至少32字符的运维令牌"

通用错误结构

接口清单

方法路径令牌用途结果
GET/api/v1/hosts只读列出主机 ID、名称和启用状态200 JSON
GET/api/v1/hosts/{hostID}/vms只读列出主机上的虚拟机摘要200 JSON
GET/api/v1/hosts/{hostID}/vms/{vm}只读读取单台虚拟机状态、内存和客户机地址200 JSON
POST/api/v1/hosts/{hostID}/vms运维创建虚拟机202 + job_id
POST/api/v1/hosts/{hostID}/vms/{vm}/actions运维启动、正常关机、重启、强制断电、挂起/恢复、自启动202 + job_id
DELETE/api/v1/hosts/{hostID}/vms/{vm}管理员删除已关机虚拟机定义，可选删除磁盘202 + job_id
GET/api/v1/jobs/{jobID}同一令牌轮询创建该任务时使用的同一运维/管理员令牌200 JSON
GET/api/v1/resources只读读取看板同款主机和虚拟机资源信息200 JSON

可直接复制的调用示例

创建虚拟机

curl -sS -X POST \
  -H "Authorization: Bearer $WVC_API_TOKEN" \
  -H "Content-Type: application/json" \
  "$WVC_BASE_URL/api/v1/hosts/$HOST_ID/vms" \
  -d '{"name":"web-01","vcpus":2,"memory_gb":4,"disk_gb":40,"network":"default","os_variant":"generic"}'

启动虚拟机

curl -sS -X POST \
  -H "Authorization: Bearer $WVC_API_TOKEN" \
  -H "Content-Type: application/json" \
  "$WVC_BASE_URL/api/v1/hosts/$HOST_ID/vms/web-01/actions" \
  -d '{"action":"start"}'

删除虚拟机定义

curl -sS -X DELETE \
  -H "Authorization: Bearer $WVC_API_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  "$WVC_BASE_URL/api/v1/hosts/$HOST_ID/vms/web-01" \
  -d '{"confirm":true,"confirm_name":"web-01","delete_storage":false}'

轮询任务

curl -sS \
  -H "Authorization: Bearer $WVC_API_TOKEN" \
  "$WVC_BASE_URL/api/v1/jobs/$JOB_ID"

契约与运维约定

  • 所有写操作都是异步任务。HTTP 202 Accepted 只表示任务已安全入队，不代表虚拟机操作已经完成。
  • 轮询 GET /api/v1/jobs/{jobID}：queued、running、succeeded、failed、cancelled。
  • 重启、强制断电、挂起和删除需要显式确认；删除还要求 confirm_name 与虚拟机名完全一致。
  • 删除默认只移除 libvirt 定义、快照/检查点元数据和 NVRAM，保留磁盘。只有显式设置 delete_storage=true 才会删除关联卷。
  • 所有响应带请求 ID；错误不会返回数据库密码、宿主机 URI、SSH 凭据或 VNC 密码。

机器可读文档：OpenAPI 3.0.3 YAML。可导入 Postman、Insomnia、Apifox、Swagger Codegen 或内部 API 网关。
