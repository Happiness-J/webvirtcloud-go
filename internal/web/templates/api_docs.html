OpenAPI

外部系统只读对接。浏览器登录后可直接打开链接；脚本使用 Bearer 令牌。

怎么对接

  1. 在服务环境变量 WVC_METRICS_TOKEN 中配置一枚随机令牌。令牌只给查看权限，不能开关机、创建或删除。
  2. 请求头使用 Authorization: Bearer <令牌>。不要把令牌放到 URL 或前端页面里。
  3. 先拉主机列表，再用返回的 host_id 拉虚拟机。所有响应都是 JSON，不含数据库密码、主机 URI、VNC 密码。
curl -sS -H "Authorization: Bearer $WVC_METRICS_TOKEN" \
  "$WVC_BASE_URL/api/v1/hosts"

WVC_BASE_URL 用实际访问地址，例如 http://127.0.0.1:8080 或 Nginx 反代后的域名。

接口

方法路径用途示例
GET/api/v1/hosts主机 ID、名称、是否启用{"hosts":[{"id":"...","name":"kvm-01","enabled":true}]}
GET/api/v1/hosts/{hostID}/vms该主机全部虚拟机把上一接口的 id 填进路径
GET/api/v1/hosts/{hostID}/vms/{vm}单台状态、客户机 IP、摘要名称含空格时做 URL 编码
GET/api/v1/resources看板同款 CPU、内存、磁盘占用可给监控系统每 15 秒拉取

未登录返回 401，令牌错误返回 401，没有该虚拟机权限返回 403，libvirt 连不上返回 502。创建、删除、电源操作走网页任务，不开放给这个只读令牌。
