OpenAPI

只读接口，适合监控、资产同步和自动化查询。

认证

浏览器登录后可直接访问。外部系统使用请求头 Authorization: Bearer <WVC_METRICS_TOKEN>。令牌只有查看权限。

接口

方法路径返回
GET/api/v1/hosts主机 ID、名称、启用状态
GET/api/v1/hosts/{hostID}/vms虚拟机名称、状态、自启动
GET/api/v1/hosts/{hostID}/vms/{vm}状态、客户机 IP、摘要
GET/api/v1/resources实时 CPU、内存、磁盘使用

接口不返回数据库密码、主机连接 URI、VNC 密码或会话令牌。
